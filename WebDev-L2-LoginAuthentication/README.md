# 🔐 Login Authentication System

## 📌 Project Overview

This project is a **Login Authentication System** developed as part of the **OASIS Infobyte Summer Internship Program (OIBSIP)**.

The application provides a simple and secure way for users to **register, log in, and access authenticated content**.

## ✨ Features

* User Registration
* User Login
* Authentication and validation
* Password validation
* Login error handling
* Secure access to authenticated pages
* Logout functionality
* User-friendly interface
* Responsive design

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the project using a local server if required.
4. Open the registration page and create an account.
5. Log in using the registered credentials.
6. Test the authentication and logout functionality.
