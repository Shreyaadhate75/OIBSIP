# 🌟 Tribute Page

## 📌 Project Overview

This project is a **Tribute Page Website** developed as part of the **OASIS Infobyte Summer Internship Program (OIBSIP)**.

The purpose of this project is to create a simple and visually appealing webpage dedicated to a respected personality and highlight their life, achievements, and contributions.

## ✨ Features

* Clean and attractive webpage design
* Introduction section
* Biography / life journey
* Major achievements
* Important contributions
* Image section
* Responsive layout
* User-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in any web browser.
4. Explore the different sections of the Tribute Page.
