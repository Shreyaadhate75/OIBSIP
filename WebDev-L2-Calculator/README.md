# 🧮 Calculator

## 📌 Project Overview

This project is a **simple and interactive Calculator Web Application** developed as part of the **OASIS Infobyte Summer Internship Program (OIBSIP)**.

The calculator performs basic arithmetic operations through an easy-to-use and responsive interface.

## ✨ Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear and delete functionality
* Decimal number support
* Interactive button interface
* Responsive design
* Simple and user-friendly UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Use the calculator buttons to perform calculations.
