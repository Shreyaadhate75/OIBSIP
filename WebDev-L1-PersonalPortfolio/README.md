# 🌐 Personal Portfolio Website

## 📌 Project Overview

This project is a **Personal Portfolio Website** developed as part of the **OASIS Infobyte Summer Internship Program (OIBSIP)**.

The portfolio website is designed to showcase my **skills, education, projects, internships, certifications, and contact information** in a professional and visually appealing way.

## ✨ Features

* Responsive personal portfolio design
* Home / Hero section
* About Me section
* Education details
* Skills section
* Projects showcase
* Internship / Experience section
* Certifications section
* Contact section
* Social media / professional profile links
* Mobile-friendly layout
* Clean and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Personal-Portfolio/
│

```

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.

The portfolio website will run directly in the browser.
