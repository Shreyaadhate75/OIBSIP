# 📝 To-Do App

## 📌 Project Overview

This project is a **To-Do List Web Application** developed as part of the **OASIS Infobyte Summer Internship Program (OIBSIP)**.

The application helps users manage their daily tasks by allowing them to add, complete, edit, and delete tasks in a simple and organized way.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Edit existing tasks
* Delete tasks
* View pending and completed tasks
* Simple and user-friendly interface
* Responsive design
* Easy task management

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
To-Do-App/
│
├── index.html

├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in any web browser.
4. Add tasks using the input field.
5. Manage your tasks using the available options.
